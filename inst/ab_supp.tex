\section{Additional simulation details}\label{sec-sim}

The birth-death-immigration-speciation simulation tracks the following:

\begin{itemize}
\tightlist
\item
  all local population sizes
\item
  running mean population size per iteration
\item
  time relative to all rates (i.e.~not simply number of iterations)
\item
  whether an incipient speciation event has occurred
\item
  the wait time to full speciation
\item
  whether full speciation has occurred
\end{itemize}

In each iteration of the simulation an event is chosen at random.
Possible events for each local population are

\begin{itemize}
\tightlist
\item
  local birth
\item
  local death
\item
  local speciation
\item
  local dispersal
\end{itemize}

There is also one possible global event: dispersal from the source pool.

If there are \(n_p\) local populations then the total number of possible
events are \(n_p \times 4 + 1\). Which event occurs during any given
simulation iteration is chosen at random according to the probability of
each event. With a local population size of \(x_i\), the probability of
each event is proportional to its respective rate:

\begin{align}
\mathbb{P}(\text{birth in pop. } i) &= \frac{\lambda x_i}{R} \\
\mathbb{P}(\text{death in pop. } i) &= \frac{\mu x_i}{R} \\
\mathbb{P}(\text{speciation in pop. } i) &= \frac{\nu x_i}{R} \\
\mathbb{P}(\text{local emigration from pop. } i) &= \frac{m_{prop}\gamma x_i}{R} \\
\mathbb{P}(\text{global emigration}) &= \frac{\gamma}{R}
\end{align}

where
\(R = \gamma + \left( \sum_i^{n_p} x_i \right) (\lambda + \mu + \nu + m_{prop} \gamma)\)
is a normalization constant.

In the case of dispersal (both local and from the source pool), the
recipient of the dispersing individual must also be chosen. We choose
the recipient local population at random with equal probability across
local populations.

Once an event is randomly sampled, the variables being tracked are
updated. Birth and immigration (local or global) augment a local
population by 1. Death decrements a local population by 1. Dispersal
events have no impact on the source of the dispersing individual. Time
is updated following the Gillespie algorithm: the sojourn time between
events is a random variable with an exponential probability distribution
with rate R: \(s \sim Exp(R)\). Each time step a random sojourn time is
sampled and added to the running total time since the start of the
simulation.

If a population experiences local extirpation all of its
speciation-related information is re-set including removing any
incipient speciation and restoring the wait time to full speciation back
to the default of \(\tau\).

If full speciation is achieved the simulation stops. If no speciation
occurs but the specified number of simulation iterations is reached, the
simulation stops. Once stopped, the simulation returns the tracked
variables of time, mean population size (i.e.~abundance), and whether
full speciation has occurred.

\section{Interpreting the simulation experiment}\label{sec-sim-res}

Now we can visually inspect the results. Our main purpose is to study
how abundance relates to speciation in this model, but first we check
other relationships to ensure the model behaves as expected. In
particular, abundance should be larger when \(\lambda > \mu\) and
smaller when \(\lambda < \mu\), supported primarily by immigration. When
\(\lambda > \mu\) populations will grow indefinitely. When birth and
death rates are equal (\(\lambda = \mu\)) the population could crash or
expand depending on small random fluctuations and random immigration.
The figure below shows exactly this pattern. Smaller abundances for
\(\lambda > \mu\) likely correspond to time bin windows earlier in the
simulation as well as those that stochastically drifted to smaller
sizes.

\subsection{Model of within genus richness and average per-species
abundance}\label{sec-arth-mod}

With the prepared data we can compute a quadratic and linear model of
genus richness versus average per-species abundance. As explained in the
main text, these models are beta-geometric generalized linear models and
are achieved with custom functions available in the \emph{abundolism}
package associated with this paper. The main function is
\texttt{glm\_bgeom} which maximizes the log likelihood function and
shares some common methods with \texttt{lm} and \texttt{glm} including
\texttt{logLik} which enables likelihood analyses such as the likelihood
ratio test.

To summarize from the main text, our full quadratic model is

\[
\begin{aligned}
y_i &\sim \text{BetaGeometric}(\alpha_i, \beta) \\
\log(\alpha_i) &= a_0 + a_1 x_i + a_2 x_i^2 \\
\log(\beta) &= b_0
\end{aligned}
\]

where \(x_i\) is average per-species abundance of lineage \(i\) and our
estimate for the observable diversification probability for lineage
\(i\) is \(1 - \hat{p_i} = 1 - \frac{\alpha_i}{\alpha_i + \beta}\).

\subsection{Assessing the choice of average per-species
abundance}\label{sec-tot-abund}

We should evaluate if the choice of average per-species abundance
produces any unintended artifacts in our analysis of how average
per-species abundance relates to within genus richness. The primary
concern would be if genera themselves somehow had a carrying capacity,
then the more species contained in a genus, the less abundant, on
average, each species would have to be. Two observations from the data
dispel this concern: first, the vast majority of genera are represented
by only a single species at a sampling location Supplementary
Figure~\ref{fig-gen-site-rich}, making the partitioning of a
hypothetical genus-level carrying capacity moot at all but the few sites
where genera are represented by multiple species.

This analysis of number of congeners and total genus abundance at the
scale of individual sampling locations is distinct from the analysis of
average per-species abundance and total genus richness at the scale of
the archipelago, the latter being the one that found a hump-shaped
relationship between abundance and richness. The sampling location-scale
analysis is intended to evaluate a possible genus-level carrying
capacity at the scale of an individual site. The sampling location-scale
analysis calculates abundance on a site-by-site basis (not averaged
across all sites as in the archipelago-wide analysis) and uses the
observed number of congeners at a site (not the total richness of a
genus from across the archipelago).
